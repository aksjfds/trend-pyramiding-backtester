# 本地网页控制台

Render 云端部署请使用专用入口，见 [Render 部署说明](RENDER.md)。下文为本机使用方式。

## 终端启动

```bash
cd /Users/a/code/trend-pyramiding-backtester
.venv/bin/pyramid-web --open
```

终端保持运行，Ctrl-C 正常退出。首次未安装环境时，先执行 `sh scripts/setup_env.sh`。

本地网页会自动读取配置目录中的 `okx.credentials.toml`（默认 `config/okx.credentials.toml`）。此前已填写的文件可直接继续使用，不需要每次输入 API 密钥。若是全新安装，只需在本机创建此文件并填写一次：

```toml
[live]
api_key = ""
api_secret = ""
passphrase = ""

[demo]
api_key = ""
api_secret = ""
passphrase = ""
```

只填写需要使用的账户，另一组可全部留空。文件已被 Git 忽略，读取时权限自动设为仅当前用户可读写。网页不提供密钥查看或下载；打开网页自动只读加载账户，不启动交易。修改密钥后重新启动网页服务。

如果某个账户已经设置了环境变量，则整组优先使用环境变量，不会混入文件中的另一套密钥；请完整设置该组的三个变量。没有任何密钥也能打开网页查看已有记录。

该便利读取仅在本地网页入口启用。Render 和直接运行的 `pyramid-okx` 仍只使用环境变量，不读取本机密钥文件或 `.env`。

也可以通过命令打开：

```bash
source .venv/bin/activate
pyramid-web --open
```

默认地址：`http://127.0.0.1:8765`。仅监听本机，使用页面会话令牌并校验请求来源。不要将此管理端口转发或代理给其他设备。支持 macOS/Linux，与原交易运行器的文件锁要求一致。

可选参数：

```bash
pyramid-web --port 8766 --config config/okx.toml --state-dir state --open
```

默认状态目录是配置文件上一级目录下的 `state/`。`PYRAMID_CONFIG` 和 `PYRAMID_STATE_DIR` 也可指定本地路径。更改策略配置后应停止策略并重启网页服务。

## 启动、停止与查看

- **只读观察**：可选实盘或模拟账户，持续检查连接、权限及市场，不下单、不改杠杆。
- **模拟交易**：向模拟盘发送策略订单，使用独立密钥和状态。
- **实盘交易**：选择该模式后，明确点击“启动实盘交易”才会运行真实交易 worker。新 K 线产生首笔开仓信号时只生成候选，不会自动下第一笔单。
- **待确认开仓**：每根新 K 线收盘后扫描全部已选币种。符合首笔开仓条件且预算允许的币种会显示信号时间、收盘价、初始止损、预计张数和剩余确认时间。点击“开仓”只是提交批准；worker 会再次核验后下单。首笔成交后，后续金字塔加仓、止损上移和退出恢复为自动策略管理。
- **停止**：向当前网页启动的进程发送正常退出信号。页面先显示“正在停止”，等正在进行的订单核对与保护操作完成后显示未运行；停止期间不能重复启动，不强制终止进程。
- **刷新账户**：打开网页自动查询，之后每分钟刷新，也可点击立即执行只读查询，显示 USDT 权益估值、可用余额、资金上限、持仓/挂单数量和候选币对。结果带检查时间，页面状态每 2 秒刷新；账户每分钟自动查询一次，手动刷新除外。失败后保留上次成功结果并明确显示错误。
- **持仓与止损**：读取本地策略记录中的合约张数、平均入场价、当前止损和加仓档数。它不是实时交易所仓位；策略停止后，两者可能不同。
- **日志**：显示当前网页会话中最近一次运行的最近 300 条日志。历史策略事件仍保存在 `state/okx-live.events.jsonl`，模拟盘使用对应 demo 文件。

网页每 2 秒刷新本地状态。关闭浏览器标签不会停止后台策略。关闭网页服务所在终端或按 Ctrl-C，会请求停止策略并等待其退出。电脑休眠、断电或强制结束进程会中断程序。

停止策略不会自动平仓或撤销交易所止损；停止后不再移动止损或加仓。

## 异常与重复启动

同一个状态目录只允许一个网页控制台。网页一次只管理一个策略进程，启动前也会检查其他终端是否在使用实盘或模拟盘状态。只读观察和交易都使用文件锁；不要通过不同状态目录让多个进程操作同一账户。

本页只停止由当前网页服务启动的进程。发现其他终端启动的策略时，显示“外部进程运行中”，请在原终端正常停止；网页不根据历史 PID 强行结束进程。

交易异常会保留暂停标记和订单意图。检查日志、账户仓位及止损，解决问题后在项目目录执行：

```bash
pyramid-okx clear-halt
# 模拟盘使用：pyramid-okx clear-halt --demo
```

若网页使用自定义配置或状态目录，命令需添加同样的 `--config` 和 `--state-dir`。然后回到网页手动启动。不要删除交易状态文件来绕过暂停。

## 选择交易币种

“交易币种”支持自动选择成交额前 5 个，或搜索并手动勾选 1–10 个 USDT 永续合约。点击“保存币种选择”后，下次启动观察或交易时生效。尚未保存时不能启动，避免误用旧设置。

实盘和模拟盘分别保存到状态目录的 `okx-live.selection.json` / `okx-demo.selection.json`，刷新网页、重启服务或 Render 重新部署后仍有效。直接执行 `pyramid-okx` 也读取同一状态目录的选择。

运行中、有持仓、未决订单或异常暂停时不能更换。历史状态已清仓时可以重新选币；交易启动时还会核对 OKX 没有任何仓位、普通挂单和算法挂单，才切换币种。切换不会增加原资金上限。

“交易账户可用 USDT”显示 OKX 交易账户的可用余额，资金账户、理财等资产不计入该字段。零余额显示为零；不满足交易条件也可查看余额，其他检查的问题会单独提示。

手动选择包含 OKX 的加密货币、股票和贵金属 USDT 永续合约，可搜索 `XAU`、`SNDK`、`CRCL`，列表会标明股票或贵金属。自动模式仍只在加密货币中按成交额选币。

持续运行、自动恢复、日志轮转及异常核查说明见 [运行维护说明](RELIABILITY.md)。网页显示“连接恢复中”时会自动重试；显示“部分行情暂不可用”时可查看日志中具体币种的原因。订单结果不明时仍需人工核查。


## 修改资金与策略参数

点击顶部资金上限或策略参数旁的“修改”，或向下滚动到“资金与策略设置”。可修改资金使用比例、逐仓杠杆、K 线周期和自动选币数量；展开“高级策略参数”可修改风险预算、指标周期、止损、加仓、保本、移动止损及各档比例。点击“保存参数”后，下次启动使用新值；未保存时不允许启动，刷新不会覆盖正在编辑的输入。

资金比例允许大于 0 且不超过 100%，杠杆为 1–125 的整数（具体币种还受 OKX 杠杆上限约束）。周期支持 15m、30m、1H、2H、4H、6Hutc、12Hutc、1Dutc。资金比例按百分数填写，例如 20 表示 20%；分档比例可填 `30, 30, 20, 20`。

运行中、存在持仓、待核对订单或异常暂停时禁止修改。保存参数只写本地状态，不设置交易所杠杆、不下单；启动交易时才核验交易所状态并应用。修改前后的账户必须一致，且交易所无持仓、普通或算法挂单，才能迁移已有空仓状态。

设置分别写入状态目录的 `okx-live.settings.json` 和 `okx-demo.settings.json`；网页、命令行及 Render 共用，重启不丢失。网页已保存的设置覆盖 TOML 中对应字段。资金比例修改时，按原本金基数重算上限，再与当前权益对应额度取较小值，不会因重新启动而自动抬高本金基数。
